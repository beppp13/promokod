# PROmok0d — стартовая версия

## Как запустить
1. Распакуйте архив.
2. Откройте папку `PROmok0d` в VS Code.
3. Откройте `index.html` через расширение Live Server (кнопка **Go Live**) или просто откройте файл в браузере.

## Что уже работает
- адаптивная главная страница в стилистике макета Figma;
- поиск по названию, категории и коду;
- фильтрация по категориям;
- карточка с подробностями промокода;
- копирование промокода;
- демонстрационная форма жалобы;
- блок показателей качества.

## Важно
Это фронтенд-прототип: данные промокодов и отправка жалоб пока демонстрационные, без подключения к PostgreSQL и серверу. Следующим этапом можно подключить базу данных и сделать сохранение данных.
